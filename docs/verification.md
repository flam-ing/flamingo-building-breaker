# 검증 기록

2026-09-07, 로컬 구현 담당 검증. Git push, PR, merge, 배포를 수행하거나 확인한 기록은 아닙니다.

## 자동 판정 테스트

`npm test`: **25개 통과**. 주요 범위:

- 8ms 키 누름/뗌이 다음 60Hz 틱까지 보존되고 한 번만 소비됨.
- 오래 누르기와 키 반복이 새로운 공격 입력을 만들지 않음.
- 긴 프레임 간격은 최대 9틱으로 제한됨.
- 준비·타격 1회·회복, 히트스톱 중 입력 큐, 상승 베기의 자원 비용.
- 보강층의 차별 판정, 실제 재질 파편 18개, 층 하강 중 공격 제한.
- 첫 현장 무입력 16.05초 생존, 첫 낙하 전 명시적 방어 안내.
- 빠른 ↓ 탭의 실제 받아치기, 일찍 누른 일반 방어의 자원 소모, 기력 부족 피격.
- 서로 다른 낙석/철골/3연속 유리 낙하 패턴.
- 짧은 X 취소, 긴 X 필살 65 소모/1회 타격/층 관통, 같은 프레임 X down/up 안전성.
- 일시정지 전체 상태 동결, blur와 공유하는 입력/방어 유예/충전/대기 공격 정리.
- 패배, 전체 재시작 초기화, 제한 시간, 잘못된 dt 거부.
- 원화 8개 알파 분리와 유효한 발 원점.

단위 테스트 일부는 특정 분기를 재현하기 위해 기력이나 층을 설정합니다. 이것을 일반 플레이 완주로 계산하지 않습니다.

## 일반 입력만으로 세 현장 완주

마지막 테스트는 `start`로 시작하고 `tick`에 실제 UI와 같은 입력 형태만 보냅니다. 건물 체력, 목숨, 점수, 시간, 자원을 직접 수정하지 않습니다. 현장 완료에서는 실제 다음 현장 버튼과 같은 `continueSite`만 호출합니다.

- 정책: 일반층 Z 반복, 매 3번째 보강층 ↑, 내려오는 파편 y>410일 때 ↓, 필살이 충분하고 여유가 있을 때 X를 65프레임 눌렀다가 해제.
- 결과: **세 현장 27층, 62.65초, 49,320점, 3하트, 받아치기 9회**.
- 실패 검증: 무입력으로 세 번 실제 피격되어 패배한 뒤 `start`로 목숨/점수/파편/단계가 초기화됨.

이것은 CPU 판정 검증이며 사람이 브라우저에서 27층을 완주했다는 뜻은 아닙니다.

## 시각 검증

구현 담당이 `npm run capture`의 실제 렌더러 출력과 8포즈 원점 아틀라스를 직접 이미지로 확인했습니다. CPU 캡처에는 HTML 메뉴가 포함되지 않으므로, 타이틀·버튼·포커스·터치 검증으로 대신하지 않습니다.

Root의 첫 실제 브라우저 검수에서는 1280×720 안의 큰 벽돌 건물, 검객 원화, 점수/3하트/하단 계기판, 짧은 Z/↑ 입력에 따른 베기·공중 자세·균열·점수 증가, 재시작 UI를 확인했습니다. 첫 버전의 너무 빠른 무입력 패배 지적은 초보자 간격으로 수정했습니다.

수정 후 실제 브라우저에서 Z/↑ 공격, 짧은 ↓ 받아치기, 패배·재시도, Esc 정지·재개를 검증했습니다. [실제 캡처와 상세 기록](browser-qa.md)을 확인하세요. 모바일 터치, 실제 브라우저의 모든 blur 경로와 사람이 27층을 완주하는 검증은 완료하지 않았습니다. 접근성은 키보드 버튼·명시적 초점·상태 알림·동작 줄이기를 구현했지만, 스크린리더로 액션 전체를 수행하는 비시각 게임 모드는 제공하지 않습니다.

## 빌드 및 경계

`npm ci`, `npm test`, `npm run build`와 `npm run capture`로 재현할 수 있습니다. 프로덕션 런타임 외부 의존성은 없고 PNG/폰트/코드는 로컬 정적 자산입니다. 개발 서버는 loopback strict **4204**입니다. 원작 참고 캡처·SWF·ROM·추출된 원작 음악은 프로젝트에 없습니다.
