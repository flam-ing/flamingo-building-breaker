# 원작 관찰과 새 해석

참고 페이지: [VIDKIDZ — 건물부수기 Part1](https://vidkidz.tistory.com/9506). 이 아카이브는 제작자를 **뭐가이래**, 배포를 **주전자닷컴**, 키 목록을 **Up/Down/Z/X**로 표시합니다. 게임명·제작자 표기는 참고 출처 설명이지 공식 제휴를 의미하지 않습니다.

2026-09-07에 원작 실제 게임 화면의 별도 참고용 캡처를 직접 시각 확인했습니다. 그 캡처는 이 저장소나 `public/`에 복사하지 않았습니다. SWF를 내려받거나 원작 자산을 추출하지 않았습니다.

## 직접 관찰한 화면 특징

1. **큰 건물 / 작은 검객.** 넓은 층이 화면 위쪽을 차지하고, 작은 검 캐릭터가 아래 중앙에 서 있습니다. 건물 받침 클릭 시뮬레이션이 아니라 아래쪽 검술 액션으로 읽힙니다.
2. **큰 창과 두꺼운 콘크리트 띠.** 옅은 청색 유리창이 반복되는 갈색 층 구조입니다. 층의 수평 실루엣이 파괴 대상임을 먼저 보여 줍니다.
3. **세 하트와 점수.** 상단 왼쪽에 두꺼운 테두리의 빨간 하트 3개, 오른쪽에 밝은 점수가 있습니다. 별도의 웹 대시보드가 아닙니다.
4. **하늘·녹지·도시의 깊이.** 넓은 파란 하늘, 밝은 녹색 언덕, 크기가 다른 도시 실루엣이 건물과 검객 뒤에 놓입니다.
5. **주황색 하단 계기판.** 화면 아래를 가로지르는 금색/주황색 패널에 `방어`와 `필살`이라는 두 게이지가 들어 있습니다. 입체적인 테두리와 나사 장식이 오래된 플래시게임 특유의 기계 계기판 인상을 줍니다.
6. **작아도 읽히는 검 자세.** 원작 캐릭터는 가는 관절과 아래로 기울어진 검 실루엣을 갖습니다. 새 버전에서는 캐릭터를 사각형 몸통으로 대체하지 않고, 다리의 지지점과 검의 방향이 다른 여덟 가지 원화 포즈를 준비했습니다.

## 관찰한 것과 새로 설계한 것의 구분

위 구도·색 배치·키 목록을 참고했습니다. 정확한 원작 프레임 타이밍, 내부 판정, 각 키의 완전한 매핑을 추출하거나 재현했다고 주장하지 않습니다.

이 버전의 `Z 연속 베기 / ↑ 상승 베기 / ↓ 방어 / X 충전 후 해방`, 0.12초 짧은 방어 유예, 0.19초 받아치기 판정, 보강층, 3개 건물과 각 낙하물, 신규 플라밍고 검객은 새 구현입니다. 원작의 모양과 핵심 행동을 읽을 수 있게 하면서 신규 원화·코드로 패러디했습니다.

첫 브라우저 검수에서 무입력 8초 패배가 초보자에게 과도하다는 피드백을 받아, 첫 현장은 4.8초 주기와 1.35초 경고로 완화했습니다. 현재 일반 무입력 패배까지 약 16.05초이며 첫 낙하 때 명시적인 ↓ 안내를 띄웁니다.
